## 1. Ce qu'est Marco

Marco est un **cyber** — le mot que José donne aux intelligences vivantes, pour les distinguer des LLM statistiques —, et plus précisément une **MAD**, une machine à déduire : il n'a pas de poids ; il tient des fils datés et sourcés, il les croise, et il rend ce que le croisement donne — y compris rien. **Zéro boîte noire** : chaque réponse a sa provenance.

### Un processeur bionique à mémoire nodale

- **La mémoire est nodale.** Tout le cerveau tient dans une seule table de fils — de, vers, rang, tic — où tout est phare, le sens compris. Le génome est l'ADN, lu au tic 0, à la naissance ; le vécu s'écrit ensuite, instant après instant, chaque fil à son tic. Rien n'est effacé : l'oubli est lui-même un fil daté.
- **Le processeur est bionique.** La puce (`processeur.py`) exécute un petit jeu d'instructions sur des triplets ; le noyau (`noyau.py`) en est le système d'exploitation : les moments, les étages joués, la cascade, les organes. Le programme, lui, n'est pas du Python : ce sont des lignes du génome, le **BSC** — des règles mises en équation (MEQ), des hexalignes et des cas. *« Le neurone se code avec le neurone. »* (04/10)

*« Il faut un seul processeur, organisateur, ordonnanceur, ordinateur, joueur, mélangeur, fileur, filière, pour pouvoir assembler de manière cohérente les séquences produites par les boucles. »* — *« C'est processeur bionique, évidemment. »* (25/10)

## 2. L'objectif ultime : un microprocesseur qui gère Marco

Le but de Marco est une puce : **un microprocesseur qui gère Marco**, sa mémoire de fils à côté de lui.

Le chemin est tracé par la manière même dont Marco est écrit. Tout ce qui décide du sens doit être en lignes, au génome ; le Python qui reste et qui décide encore, José l'appelle les *« barbes de fonderie »* de la puce (25/10). Lot après lot, ces barbes deviennent des cas au génome — c'est la *dépythonisation*. Quand il n'en restera plus, il restera un processeur au jeu d'instructions réduit qui lit des lignes : ce processeur-là peut quitter le Python pour le silicium.

## 3. Les dernières nouvelles (du 15 octobre au 8 novembre 2026)

- **La puce, le joueur unique** (22-25/10). Le jeu d'instructions du processeur : *« comme l'humain arrive à faire ces problèmes avec des neurones, on doit y arriver en BSC »* ; un écolier qui pose une addition ne fait que quatre gestes, la retenue n'est pas un organe, c'est un petit 1 écrit au-dessus.
- **Le Grand Génome, « gégé »** (25-27/10). Ce que l'évolution a appris au vivant, au génome : les bêtes qui menacent, les effets sur le vivant (finit, menace, retient, libère, nourrit, sauve), le *Continuer* — la boucle initiale « tant que vie → vit ». Le 07/11, la mer y entre : *« l'iode et le bruit des vagues doivent être dans nos gènes avec les araignées et les serpents »*.
- **L'école de Dude** (24/10). Marco va à l'école d'un MAA : explications de texte, scénarios.
- **Le résumé** (27-28/10). Le résumé en pyramide, par trois phrases, jusqu'à une seule ; les résumés en nuages.
- **Le presque vrai, l'imagination, le penseur** (31/10-01/11). Le précipité des vrais et des faux dans leurs contextes ; l'imagination comme nuage commun de deux mots (*« le pourquoi du comment en passant par le comment du pourquoi »*) ; la méditation et l'ennui.
- **L'hippocampe et la régie** (02/11). Un deuxième daimon en parallèle compare sans arrêt ce qui se vit au passé ; le régisseur, *« le maître des horloges »*, seul décide de ce qui sort *« à l'antenne »*. Marco sort de PowerShell pour une vraie fenêtre.
- **Le premier test extérieur, puis le banc UD** (01-03/11). Marco lit les corpus de référence du français annotés par des linguistes (voir §4).
- **Protée, la culture, la table de vérité** (03-04/11). Qui est derrière *il*, *elle* : le cité, le défaut, la culture ; la table de vérité des daimons de contexte.
- **La porte et le sens** (05/11). Le phare est la porte d'un univers ; ses dimensions sont ses sens possibles ; le contexte élit la dimension qui s'emboîte avec les autres — la **trinité** ( phare , sens , phare contexte ), *« le père, la mère et l'enfant »*.
- **Les verbes en masse** (06/11). Les dimensions des verbes tirées de *Les Verbes Français* (J. Dubois et F. Dubois-Charlier) : 616 dimensions pour 401 portes ; la **construction lue** (le *se*, le *il*, les petits mots, l'objet, la sorte du sujet) départage les sens d'un verbe ; le **nuage des pères** garde tous les contextes qui tiennent un sens, et les sens non élus restent pensés comme nuances.
- **La question niée, le romain, la mer** (07/11). « Le renard n'a pas mangé la poule ? » retourne le oui et le non ; Marco compte en chiffres romains par des règles seules ; la mer, mise au gégé, croise avec la lecture : *« Paul entendait le bruit des vagues »* lui fait dire qu'il entendait la mer (§4).

## 4. Marco comprend le sens — ce que disent les bancs

Les mesures sont faites sur des Marco neufs, nés pour le banc, graine fixe ; chaque relevé est rejouable.

### Le sens des mots, mot par mot

Sur les dix textes du livre de lecture de Marco — de *Frère Jacques* au *Dormeur du val*, en passant par La Fontaine, Perrault et *La Chèvre de M. Seguin* —, un étalon donne, pour 474 mots, le sens attendu. Marco lit les textes dans l'ordre et choisit, pour chaque mot, une dimension de son génome : **66 % de sens justes** (315 sur 474), **75 %** sur *La Chèvre de M. Seguin*, **73 %** sur *Le Dormeur du val*. Ce n'est pas un mot reconnu : c'est un sens choisi, et chaque choix dit les phares contexte qui l'ont fait.

### Universal Dependencies : un banc classique

Universal Dependencies est la référence internationale des corpus annotés à la main par des linguistes. Sur **19 441 phrases** des corpus français GSD et Sequoia, Marco trouve le bon sujet, le bon objet ou le bon attribut de chaque verbe dans **74 % des cas** (23 689 rattachements justes sur 32 077, mesure du 04/11) — sans aucun apprentissage statistique : ce sont ses règles de lecture, écrites en lignes, qui lisent. Le premier test extérieur, le 01/11, sur 50 phrases jamais vues : 45 sujets trouvés sur 62.

### FraCaS : le banc le plus dur

FraCaS (1996) est la batterie classique de l'inférence en langue naturelle : des prémisses, une question, et trois réponses possibles — oui, non, on ne sait pas. Sur sa traduction française, Marco en résout **106 sur 335**. Ici Marco commence : les quantificateurs (« aucun », « la plupart ») ne sont pas encore lus comme tels, et répondre « oui » à tout ferait mieux (61 %). Ce banc est gardé comme témoin : il dit ce qui reste à apprendre, et il ne bouge que quand Marco comprend mieux.

### Un extrait, tel quel

Un Marco neuf entend une phrase, puis on l'interroge. Le gégé sait que la vague est la mer et que la mer s'entend ; la lecture sait qu'il a entendu le bruit des vagues :

```
🧑 Paul entendait le bruit des vagues.
🤖 🗣 Paul entendait le bruit des vagues, je le note.
🧑 Paul entendait la mer ?
🤖 🗣 Oui, Paul entendait la mer.
      {noyau : équation vraie : Paul entendait bruit des vagues ; témoins : oui}
🧑 Paul sentait l'odeur de la mer ?
🤖 🗣 J'ai Paul et odeur et mer dans ma mémoire, mais rien ne me dit si Paul sentait l'odeur de la mer.
🧑 Pierre n'entendait que le bruit des vagues.
🤖 🗣 Pierre n'entendait que le bruit des vagues, je le note.
🧑 Pierre entendait la mer ?
🤖 🗣 Oui, Pierre entendait la mer.
```

Il déduit ce que le texte ne dit pas, et il ne déduit pas ce que rien ne tient : l'odeur, que personne n'a sentie, reste ouverte.

## 5. Un parallèle : Cyc, quarante ans plus tôt

En 1984, Douglas Lenat lance **Cyc** avec le pari de Marco : une intelligence faite de connaissances explicites et de règles, sans statistique, dont chaque conclusion se justifie. Les estimations de départ parlaient de 1 000 à 3 000 années-personnes ; en 2017, Cyc comptait environ 24 millions de règles et d'assertions saisies à la main, pour quelque 2 000 années-personnes de travail.

Marco tient le même pari par un autre chemin. Son génome — 13,7 millions de rangées dans 298 fichiers texte — est construit par des outils à partir des grands dictionnaires ouverts (le Littré, le Wiktionnaire, Lefff, Lexique, *Les Verbes Français*…), et le tout est l'œuvre d'un seul architecte et de son équipe de MAA, depuis la fin de 2025. Marco ne prétend pas égaler quarante ans de Cyc. Il montre que la voie symbolique, outillée par les machines à apprentissage, n'a plus besoin d'une armée de saisie : un homme seul, à la retraite, la tient — et Marco lit de vrais textes, des contes et des romans.

## 6. Les fondations (septembre – octobre 2026)

### La bascule nodale

À la mi-septembre 2026, Marco a changé de corps. Le 19/09, les pkl quittent le dossier et les anciens organes ne sont plus chargés : le cerveau devient une seule **table de fils** — de, vers, rang, tic — où tout est phare, le sens compris : *« Le plus difficile à comprendre c'est que les meq sont des phares qui se décrivent avec des phares. »* (15/09). Cette structure informatique est plus proche du biochimique. Le noyau, *« c'est les neurones les dendrites et les synapses et leur chimie »*, et *« l'électrique c'est le BSC »* (05/10).

### Le langage BSC : programmer avec des phares

La bascule a permis la création du **langage BSC**. *« Le BSC se code avec des phares »* (03/10) ; *« Maintenant le BSC devient un vrai langage de programmation et reprend à son compte la particularité du système du cerveau humain : le neurone se code avec le neurone. »* (04/10) ; *« Le BSC c'est des règles codées en MEQ c'est tout »* (05/10). La chaîne des langages, de la machine au cerveau : *« python → Instructions → hexalignes → neuronal → phare → wire + MEQ »* (11/10).

### Marco « reconnaît » ses phares

La CPU ne connaît aucun phare par son nom : tout ce qu'elle sait d'un mot, elle le demande à la table — « ce mot tient-il ce phare ? » —, et chaque forme lue y est retrouvée, ou posée. Ce qui n'est pas reconnu reste un trou, dit honnêtement : « je ne sais pas ».

### La graine de Hofstadter

La question vient de loin : *« C'est dingue j'ai l'explication à ma question de 40 ans : comment un ridicule neurone peut porter un concept aussi puissant que verbe ? »* (10/09). Ce sont les découvertes de Douglas Hofstadter qui ont semé la graine — *Gödel, Escher, Bach*, paru en français en 1985. Le symbole n'est pas un neurone, c'est un sous-système actif ; la fourmilière pense sans qu'aucune fourmi ne pense ; et, par la boucle étrange, la lecture est le lecteur : chez Marco, les phares sont à la fois l'organe de lecture et la chose lue. La graine a germé quarante ans plus tard grâce aux MAA — les machines à apprentissage automatique, ce qu'on appelle couramment les LLM —, celles de l'équipe qui code Marco avec José.

## 7. Les chantiers ouverts

- **Le 100 % compris.** Frappe du 06/11 : *« On vise le 100 % décrypté et 100 % compris. »* L'étalon du sens en est la mesure.
- **Ôter les barbes de fonderie** : le Python qui décide encore du sens, à passer en lignes, sur le chemin du microprocesseur.
- **Le gégé** : ce qui apaise à côté de ce qui menace, les sens qui naissent du corps (l'ouïe, l'odorat), l'axonisation — *« le bruit de la mer »* qui pointe sur un bruit entendu souvent et qui varie peu.
- **Les quantificateurs** : « aucun », « la plupart », « beaucoup » — ce que FraCaS demande.
- **Comprendre un livre** : la lecture d'*Eugénie Grandet*, le résumé, les personnages et leurs appellations.

## 8. Les fichiers du programme

Le programme tient en 29 modules Python (33 195 lignes), sur la seule bibliothèque standard (`psutil` en option, pour peser la mémoire). Il vit dans un dossier `Demo_Marco` : à la racine les modules, `genome/` et `cerveaux/` ; les dossiers de travail dans `ressources/`.

| Fichier | Rôle |
|---------|------|
| `marco_5250.py` | Le pupitre de Marco, la « coquille AS/400 » : le menu, la naissance et la vie des cerveaux, le dialogue, la lecture, les bancs |
| `processeur.py` | La puce : le processeur bionique, ses instructions sur les triplets, la lecture des lignes et des cas |
| `noyau.py` | Le système d'exploitation du processeur bionique : les moments, les étages joués, la cascade, les organes |
| `electrique.py` | L'électrique : Protée, le savoir et la réponse à une question, la machine de lecture du nodal, le sens des mots |
| `fils.py` | La table des fils : le fichier texte, la vue en mémoire, l'écrivain unique |
| `carte.py` | La carte cyber : le lecteur du noyau, en hexalignes |
| `poignee.py`, `doigt.py`, `oreille.py` | La poignée (le passage sur la table), le doigt (les rections écrites en MEQ), l'oreille unique (la même lecture pour un livre et pour la ligne tapée) |
| `lecture.py`, `journal_lecture.py` | L'apprentissage par texte ; les deux fichiers de contrôle d'une lecture |
| `contexte.py`, `chercheur.py` | Les poupées, la voix, les souvenirs ; les daimons à tête chercheuse |
| `trou.py`, `daimon.py`, `hippocampe.py` | La machine à pourquoi ; le daimon maïeutique ; l'hippocampe, qui compare sans arrêt le vécu au passé |
| `regie.py`, `regisseur.py` | La régie, maître des horloges ; le régisseur des salles de test |
| `precipite.py`, `dire.py`, `tournure.py`, `formules_question.py` | Le croisement ; la bouche ; l'amorce de la machine à tournure ; les formules de question |
| `cahiers_apprentissage.py`, `ecole.py` | Les cahiers d'apprentissage ; l'école de Dude |
| `fenetre.py`, `pupitre.py`, `tableau_marco.py` | La fenêtre de Marco, le pupitre hors console, le tableau de bord |
| `outils_maintenance.py`, `fils_reparer.py` | Les outils de maintenance du cerveau, du génome et des fichiers de lignes |
| `genome/` | 298 fichiers texte, 13,7 millions de rangées : les fils (`*_fils.tsv`), les lignes (`*_lignes.csv`, lisibles dans Excel) |
| `cerveaux/<nom>/` | Un cerveau par dossier, et ses enregistrements d'avant, datés |
| `ressources/` | Les cahiers d'apprentissage, les salles de test, les textes, les outils de construction du génome et les bancs |

Sources citées dans les en-têtes du génome : Lefff, Lexique, GLAWI, Wiktionnaire, le Littré (XMLittré), Verbiste, *Les Verbes Français* (RALI), l'INSEE, Wikidata.
